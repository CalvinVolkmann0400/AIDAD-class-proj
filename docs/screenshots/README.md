## How to retake one yourself

1. Start the app: `uv run streamlit run app.py`
2. Pick the role on the start screen and open the page you want.
3. Press **Windows + Shift + S**, drag a box around the browser window, and the picture is copied.
4. Paste it straight into PowerPoint (Ctrl + V), or open Paint, paste, and save it into this folder.
